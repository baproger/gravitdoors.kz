# Исходник логотипа

`logogravit.jpeg` — оригинал от владельца: 640×640, белый с золотом на чёрном,
вокруг знака широкие пустые поля.

Из него собраны файлы в `public/images/` (скриптом, вручную не правились):

| Файл | Что это | Где используется |
|---|---|---|
| `gravit-logo.png` | знак с полями, обрезанный по содержимому, чёрная плашка | шапка панели, светлая тема |
| `gravit-logo-light.png` | то же без фона | шапка панели в тёмной теме, витрина страницы входа |
| `gravit-favicon.png` | одна дверь, 64×64 | значок вкладки |
| `gravit-icon.png` | одна дверь, 512×512 | запас: иконка приложения, соцсети |

Если логотип заменят, пересобрать всё из нового исходника: обрезать по границам
непустого содержимого, а для версии без фона сделать чёрный прозрачным, оставив
цвет пикселей как есть — иначе золото выцветает в лимонный.

`LoginPageTest::test_brand_logo_is_wired_up_and_the_files_exist` проверяет, что
файлы на месте: страница откроется и с битой картинкой, просто вместо знака
будет рамка с крестиком.
