# Знак завода

`logogravit.jpeg` — оригинал от владельца: 640×640, белая дверь с золотом на
чёрном. Сам знак занимает полосу 586×144, остальное — пустое чёрное поле,
поэтому вставлять файл как есть нельзя: в шапке он был бы втрое мельче, чем мог.

## Что где стоит

| Файл в `public/images/` | Что это | Где используется |
|---|---|---|
| `gravit-icon.png` | одна дверь, 512×512, чёрный квадрат | сайдбар — круглой иконкой (`resources/views/filament/brand.blade.php`) |
| `gravit-logo-light.png` | знак с надписью, без фона, 620×178 | витрина страницы входа: она синяя, чёрная плашка читалась бы наклейкой |
| `gravit-favicon.png` | та же дверь, 64×64 | значок вкладки |

В сайдбаре знак собран разметкой, а не картинкой: круглая иконка плюс
«Gravit ERP» шрифтом панели. Широкий логотип с надписью занимал всю ширину
сайдбара и всё равно не читался в 32 пикселя высотой, а набранное название
остаётся чётким и подхватывает цвет темы.

## Если логотип заменят

Пересобрать из нового исходника, а не править файлы вручную. Два правила, на
которых легко ошибиться:

1. **Обрезать по непустому содержимому.** Границы ищутся по порогу яркости:
   всё, что светлее ~28, — рисунок.
2. **Для версии без фона цвет пикселей не трогать.** Соблазн поделить цвет на
   прозрачность (как поступают с полупрозрачным белым) выцвечивает золото в
   лимонный. Прозрачность берётся по яркости, а сам цвет остаётся как есть;
   до яркости своей буквы поднимается только тёмная кромка сглаживания —
   иначе вокруг текста остаётся серый ореол, заметный на светлом фоне.

Для круглой иконки холст берётся в полтора раза больше знака: круг режет углы
квадрата, и при меньшем поле у двери обрезались бы уголки рамки.

Широкая версия на чёрной плашке сейчас никому не нужна и потому не хранится.
Понадобится для печатных документов — собирается из исходника тем же способом,
без снятия фона.
